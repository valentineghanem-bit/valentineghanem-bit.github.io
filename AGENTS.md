# Repository-specific release instructions

This repository is Valentine Golden Ghanem's personal website, built with Jekyll and deployed to GitHub Pages. It is not a Ghana research-artifact repository.

For work in this repository, the research-artifact release gate is explicitly waived: do not require research dashboards, posters, manuscripts, research README inventories, or research-specific pre-commit artifacts before publishing website changes. Do not create dummy research deliverables to satisfy that gate.

Use website-specific release checks instead: run the production Jekyll build, inspect the staged diff, keep generated builds and local planning/QA files out of commits, push only intended website sources, and confirm the GitHub Pages workflow and affected live URLs. Keep secrets and private data out of commits. This exemption applies to this repository only.
